# Personal Knowledge Vault

Welcome to your personal knowledge vault!

This repository is your private, Git-backed vault for Markdown notes and assets.

## Structure

```text
├── notes/
│   ├── programming/       # Technical & programming notes
│   ├── projects/          # Active project documentation and specs
│   └── miscellaneous/     # Quick notes, ideas, and scratchpads
├── assets/
│   └── images/            # Embedded images, diagrams, and attachments
├── templates/             # Markdown templates for new notes
├── .vault/
│   └── config.json        # Vault configuration and metadata
└── README.md              # Vault root overview
```

## Note Format

Notes are standard Markdown (`.md`) files and can optionally include YAML frontmatter:

```markdown
---
title: Note Title
tags:
  - topic
created: YYYY-MM-DD
updated: YYYY-MM-DD
---

# Note Title

Your note content goes here...
```

## Portability & Ownership

All contents in this repository are owned by you and remain standard Markdown files compatible with any Markdown editor, Git client, or Obsidian/Logseq-style tool.
