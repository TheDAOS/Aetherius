# Welcome to Your Vault

This is your first note in your personal knowledge vault!

## Key Features

- **Markdown-first**: Write in standard Markdown with YAML frontmatter.
- **Git-backed**: Every save is committed directly to your private GitHub repository.
- **Hierarchical organization**: Create folders and subfolders to organize your notes.
- **Templates**: Start new notes quickly using templates in the `templates/` folder.
